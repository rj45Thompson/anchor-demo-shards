# anchor-demo-shards

The 512 knowledge-graph shards (`shards/000.json.gz` .. `511.json.gz`, 66.4 million facts) that the Anchor engine demo
(https://rj45thompson.github.io/anchor-demo/engine.html) loads in the browser. Moved here from the anchor-demo repo on
2026-11-10 so that site stays well under GitHub Pages' size limit; served at https://rj45thompson.github.io/anchor-demo-shards/shards/.
